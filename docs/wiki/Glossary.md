# Glossary

- **Mandate** — an elected office or candidacy (vereador → Presidência) registered in `mandates`.
- **Consensus cluster** — a group of near-duplicate proposals merged into one signal by `consensus`
  (pgvector embeddings).
- **SLA clock** — the public, time-bound response window a `consequence`-engine starts when a
  clustered proposal crosses its support threshold.
- **Public silence** — the recorded outcome when an SLA expires with no official response.
- **Scorecard** — the permanent public record per politician: promises vs delivery, answered vs
  ignored, response latency.
- **Space** — a participation context (process, assembly, initiative, consultation, mandate).
- **Component** — a participation tool (proposals, votes, comments, …) mounted into a space.
- **Tier 0/1/2/3** — the dependency layers that define parallel agent fan-out (PARALLELIZATION.md).
